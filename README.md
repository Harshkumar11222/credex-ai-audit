# Credex AI Audit

AI SaaS spend optimization platform that audits organizational AI tool usage and recommends cost-saving alternatives.

## Features
- AI spend audit
- Multi-tool analysis (ChatGPT, Claude, Cursor)
- Shareable audit reports
- Lead capture with Supabase
- AI-generated summary
- CI testing pipeline

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
- Vitest

## Local Setup
```bash
npm install
npm run dev
